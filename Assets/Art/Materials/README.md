# Low-Poly Material Suggestions

Create simple shared materials:

- Road: dark blue-gray or asphalt
- Lane Lines: warm white
- Coin: gold/yellow
- Obstacles: red/orange for visibility
- Trees: brown trunk + green leaves
- Rocks: gray/brown
- Ground/Environment: sandy beige or grass green

For a stylized portfolio look:

- Use flat colors.
- Keep roughness high.
- Avoid heavy textures.
- Use directional light plus soft ambient lighting.
